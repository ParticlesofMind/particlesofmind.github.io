# particlesofmind.github.io

The Particles of Mind website, served by GitHub Pages at https://particlesofmind.github.io.

- `/run-luke-run/privacy/` and `/run-luke-run/support/`: the privacy policy and support page linked from the App Store listing of Run Luke, Run!
- `/scrub-rush/privacy/` and `/scrub-rush/support/`: the same for Scrub Rush

Plain HTML and one stylesheet (`style.css`), no build step and no third-party requests. Add a folder per app.
